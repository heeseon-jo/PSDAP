# PSDAP analysis code

Analysis code accompanying **A harmonized dataset of pharmacological and herbal perturbagen-induced transcriptomic signatures** (*Scientific Data*).
The repository contains the core code used to build the perturbation
signatures and the released data files of PSDAP. Dataset-specific
preprocessing (reading each resource, renaming columns, etc.) and large
intermediate files are not included.

## Folders
| Folder | Step | Contents |
|---|---|---|
| [`Differential expression analysis`](Differential%20expression%20analysis) | Differential expression | DEG analysis of RNA-seq (DESeq2) and microarray (limma) data |
| [`Ortholog mapping`](Ortholog%20mapping) | Gene symbol conversion | Rat-to-human & mouse-to-human ortholog table and the symbol conversion function |
| [`Signature standardization`](Signature%20standardization) | Signature standardization | Ranked gene lists and directional (up / down) gene sets at six stringency levels |
| [`Enrichment analysis`](Enrichment%20analysis) | Enrichment analysis | Hypergeometric test and Kolmogorov-Smirnov (KS) test |
| [`Similarity Calculation`](Similarity%20Calculation) | Similarity | Pairwise similarity calculation between signatures |
| [`Generation of released files`](Generation%20of%20released%20files) | Released files | Scripts that generate the metadata, enrichment, similarity and signature files of the release |
| [`Data Integrity check`](Data%20Integrity%20check) | Validation | Automated integrity check of the metadata tables |

Each folder has its own `README.md` describing the scripts, their inputs and
outputs, and points to be aware of.

## Requirements

- R 4.4.1. Packages are listed in the header of each script and in the folder
  README.

## Not included

- Raw data and the internal database. Scripts that query the database
  (`Generation of released files`) need access to it; connection settings are
  not part of this repository.
- Ortholog mapping tables (`.csv` / `.Rdata`). They are regenerated by
  `Ortholog mapping`; because Ensembl is updated
  regularly, a new run can give slightly different tables.
